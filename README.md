# Лабораторна робота №3 — базові операції

Група: **ФІТ-2-15**

Чотири завдання реалізовані в одній консольній програмі C#.

**Сторонні бібліотеки та NuGet-пакети не використовуються.** Програма використовує тільки стандартні можливості .NET.

## Запуск

Проєкт налаштований на .NET 11:

```powershell
dotnet run
```

У головному меню потрібно обрати завдання від `1` до `4`. Пункт `0` завершує програму.

## Завдання

### 1. Зміна порядку цифр числа

Програма приймає ціле число практично будь-якої довжини, тобто не обмежується типами `int` або `long`. Обмеженням є лише доступна пам'ять.

Знак числа зберігається.

Приклади:

- `123` → `321`
- `1000` → `1`
- `-453` → `-354`
- `123456789012345678901234567890` → `098765432109876543210987654321` після числової нормалізації → `98765432109876543210987654321`

Якщо введено лише одну значущу цифру, програма виводить попередження, що змінювати порядок цифр немає сенсу, і залишає число без змін.

Початкові нулі трактуються як незначущі. Наприклад, `000123` обробляється як число `123`.

### 2. Видалення перших X слів або цифр

Програма читає довільний текст та невід'ємне ціле число `X`.

Якщо введено звичайний текст, програма видаляє перші `X` слів/елементів, розділених пробілами.

Якщо введено **лише ціле числове значення**, програма попереджає, що це не слова, а число, і переходить у режим роботи з цифрами: видаляє перші `X` цифр самого числа.

Приклади:

- `Hello big world`, `2` → `world`
- `Nice red car and green eyes`, `4` → `green eyes`
- `123456789`, `2` → попередження про числове значення, результат `3456789`
- `-123456`, `2` → попередження про числове значення, результат `-3456`
- `Hello 123 big world`, `2` → попередження для `123`, результат `big world`

Якщо `X = 0`, введене значення залишається без змін. Якщо `X` не менше кількості цифр або елементів, результат буде порожнім.

### 3. Обчислення площі фігури

Підтримуються:

- квадрат — сторона × сторона;
- круг — π × радіус²;
- прямокутник — сторона 1 × сторона 2;
- трикутник — основа × висота / 2.

Програма приймає і крапку, і кому як десятковий роздільник.

Приклади:

- квадрат зі стороною `2.5` → `6.25`;
- прямокутник зі сторонами `3` та `4.5` → `13.5`;
- трикутник з основою `6` та висотою `2,1` → `6.3`.

У початковій умові для квадрата наведено `6.26`, але математично правильний результат `2.5 × 2.5 = 6.25`.

### 4. Заміна символів

Позиції символів рахуються від 1, включно з пробілами та іншими символами тексту.

Правила виконуються з таким пріоритетом:

1. кожен 15-й символ → `?`;
2. кожен інший 3-й символ → `X`;
3. кожен інший 5-й символ → `9`.

Отже, для 15-го символу використовується саме `?`, а не `X` чи `9`.

Приклад у початковій умові не повністю відповідає сформульованим правилам, тому реалізація виконує саме текст умови.

## Обробка помилок

Програма перевіряє числове введення і пропонує повторити його при помилці. Після виконання кожного завдання користувач повертається до головного меню.
