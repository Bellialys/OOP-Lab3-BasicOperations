# Лабораторна робота №3 — базові операції

Чотири завдання в одній консольній програмі C#. Сторонніх бібліотек та NuGet-пакетів немає: використовується лише стандартна бібліотека .NET.

## Запуск

Потрібен .NET SDK 11, відповідно до наявного файлу проєкту.

```powershell
dotnet run
```

Оберіть завдання від `1` до `4`. Після виконання програма повертається до меню; `0` завершує роботу.

## Завдання та приклади

1. **Обернення числа зі збереженням знака.** Щонайменше 5 цифр (знак не враховується), діапазон введення — `Int64`. `12345` → `54321`, `10000` → `1`, `-45321` → `-12354`. Коротші числа відхиляються відповідно до тексту умови, хоча приклади в ній містять менше 5 цифр.
2. **Видалення перших X слів.** Слова розділяються пробілами, табуляціями та іншими пробільними символами. `Hello big world`, `2` → `world`; `Nice red car and green eyes`, `4` → `green eyes`. При X = 0 текст залишається без змін; якщо X не менше кількості слів, результат порожній. Від'ємне X не допускається. Форматування тексту, що залишився, зберігається.
3. **Площа фігури.** Квадрат: сторона²; круг: π × радіус²; прямокутник: добуток сторін; трикутник: основа × висота / 2. Розміри додатні; підтримуються крапка і кома як десятковий роздільник. Сторона `2.5` дає `6.25` (у завданні помилково `6.26`); сторони `3` і `4.5` дають `13.5`; основа `6` та висота `2,1` дають `6.3`.
4. **Заміна символів.** Позиції рахуються від 1, включно з пробілами: кожна 15-та → `?`, інші кратні 3 → латинська `X`, інші кратні 5 → `9`. Приклад результату в умові не відповідає цьому правилу.

Помилкове числове введення пропонується повторити. Закриття потоку введення коректно завершує програму.
